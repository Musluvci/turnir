# 🏆 Tournament Management System (v. 27.py)

Це веб-додаток на базі **Streamlit** для повної автоматизації проведення турнірів, хакатонів та навчальних змагань. Система дозволяє керувати процесом від реєстрації команд до виставлення оцінок журі та формування прозорої таблиці лідерів.

---

## 🚀 Основні можливості

Програма підтримує чотири ключові ролі користувачів:

1. **🔴 Адміністратор (Admin):**
   * Створення нових турнірів та керування їхніми статусами.[cite: 1]
   * Публікація завдань для конкретних турнірів.[cite: 1]
   * Модерація списку команд та видалення некоректних записів.[cite: 1]
   * Реєстрація офіційних членів журі.[cite: 1]

2. **🟢 Учасник/Команда (Team):**
   * Реєстрація у вибраному турнірі.[cite: 1]
   * **Мульти-командний режим:** можливість створювати кілька команд та перемикатися між їхніми профілями.[cite: 1]
   * Здача проєктів (посилання на GitHub та відео-демо).[cite: 1]

3. **🔵 Журі (Jury):**
   * Зручний інтерфейс для перегляду робіт учасників.[cite: 1]
   * Оцінювання проєктів за допомогою інтерактивних слайдерів.[cite: 1]
   * Додавання текстових коментарів до оцінок.[cite: 1]

4. **🟡 Організатор (Organizer):**
   * Спеціальний доступ для моніторингу загального прогресу та перегляду результатів.[cite: 1]
