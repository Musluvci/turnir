# 🏆 Tournament Management System (v. 27.py)

Це веб-додаток на базі **Streamlit** для повної автоматизації проведення турнірів, хакатонів та навчальних змагань. Система дозволяє керувати процесом від реєстрації команд до виставлення оцінок журі та формування прозорої таблиці лідерів.

---

## 🚀 Основні можливості

Програма підтримує чотири ключові ролі користувачів:

1. **🔴 Адміністратор (Admin):**
   * Створення нових турнірів та керування їхніми статусами.
   * Публікація завдань для конкретних турнірів.
   * Модерація списку команд та видалення некоректних записів.
   * Реєстрація офіційних членів журі.

2. **🟢 Учасник/Команда (Team):**
   * Реєстрація у вибраному турнірі.
   * **Мульти-командний режим:** можливість створювати кілька команд та перемикатися між їхніми профілями.
   * Здача проєктів (посилання на GitHub та відео-демо).

3. **🔵 Журі (Jury):**
   * Зручний інтерфейс для перегляду робіт учасників.
   * Оцінювання проєктів за допомогою інтерактивних слайдерів.
   * Додавання текстових коментарів до оцінок.

4. **🟡 Організатор (Organizer):**
   * Спеціальний доступ для моніторингу загального прогресу та перегляду результатів.

---

## 🛠 Технологічний стек

* **Мова програмування:** Python 3.12
* **Веб-інтерфейс:** Streamlit
* **Обробка даних:** Pandas
* **База даних:** JSON (локальне збереження у файл tournament_db.json)
